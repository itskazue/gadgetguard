Mabilis at madaling paraan para mapagana ang project sa computer o laptop:

------------------------------------------------------------------------
HAKBANG 1: KINAKAILANGAN (REQUIREMENT)
------------------------------------------------------------------------
Kailangan mayroong naka-install na Node.js sa iyong PC/Laptop.
Kung wala pa, i-download at i-install ito mula sa official website:
👉 https://nodejs.org/ (I-click at i-install ang "LTS Version")

------------------------------------------------------------------------
HAKBANG 2: 1-CLICK RUN (NAPAKADALI!)
------------------------------------------------------------------------
1. I-extract ang ZIP file o buksan ang folder na ito.
2. I-double click lamang ang file na:
   👉 START_SYSTEM.bat

3. Awtomatikong magbubukas ang server at ang website sa iyong browser sa:
   👉 http://localhost:3000/
